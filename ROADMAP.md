# Roadmap

План подготовки следующего релиза. Текущие ограничения реализации описаны в [Known Issues](https://gocream-labs.github.io/pysberbank/next/known-issues/), порядок выпуска - в [Releasing](https://gocream-labs.github.io/pysberbank/next/releasing/).


## Release Preparation

- [x] Исключить параметры запросов и содержимое ответов из debug-логов.
- [x] Сохранять нулевые и пустые значения при подготовке запроса, удаляя только `None`.
- [x] Подготовить CI, автоматизацию релизов и сайт документации.
- [ ] Нормализовать обработку HTTP-ошибок и некорректных ответов API с регрессионными тестами.
- [ ] Исправить существующие тестовые моки и ручной набор тестов.
- [ ] Привести код и тесты к настроенным правилам Ruff.
- [ ] Проверить внешние настройки GitHub Actions, PyPI Trusted Publishing и GitHub Pages.
- [ ] Согласовать номер первого релиза и проверить установку опубликованных артефактов.


## Documentation

- [ ] Сверить параметры и ограничения методов с официальной инструкцией унаследованного API.
- [ ] Привести старые docstring к Google-style для справочника API.


## Compatibility

- Сохранять публичные методы, сигнатуры и формат ответов вне явно согласованных изменений.
- Проверять Python 3.10-3.14 и отдельное окружение Python 3.10 с Requests 2.28.2.
- Миграцию приложений-потребителей выполнять отдельно после проверки релизного кандидата.


## Deferred Work

Изменение иерархии исключений, исправление публичных имён `anguage` и `DEFAULT_CURREBCY`, расширение набора параметров API и переход на `requests.Session` требуют отдельного решения с учётом совместимости. Примеры отдельного Flask-приложения не входят в подготовку текущего релиза.
